A little about me

Hello, I’m Roushan!

I’m a Palantir-certified AI Engineer and Foundry Application Developer based in India, with hands-on expertise across Ontology modeling, Pipeline Builder, Workshop applications, automation tooling and API integrations.

Start with the source. Build for the user.

On a new pipeline my first move is to trace the data back to whoever actually produces it and find where it still gets edited by hand — that is usually where the breakage lives, and it shapes the schema more than any diagram does. I write requirements back to stakeholders as the object types and properties they imply, because “we need a report on X” turns out to mean three different things the moment X has to be named in the Ontology. Good modeling, to me, means an object a business user recognises without a legend: link types that read as sentences, no catch-all string columns standing in for a real type, and every property traceable to a source that someone owns.
