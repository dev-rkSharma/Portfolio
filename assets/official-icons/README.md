# Icon sources

Palantir technology UI symbols and navigation use unmodified path data from Palantir Blueprint. They are official library icons, not claims of dedicated product logomarks. The Foundry label uses the parent Palantir mark already in the portfolio. Other technology brand marks retain the existing Simple Icons geometry and brand colors.

Exact Blueprint source URLs are recorded in sources.json; its license is in LICENSE-blueprint.txt.

Palantir brand reference: https://www.palantir.com/platforms/foundry/

Product artwork update: Ontology Manager (blue cube), Pipeline Builder (teal pipeline), Workshop (purple application window), Quiver (purple chart), and the AIP mark now use crops of the actual artwork in Palantir documentation. They preserve source colors and geometry. Exact image URLs are recorded in product-art-sources.json.
